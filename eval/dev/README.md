# 拒答阈值调参记录（调参集 ≠ 评测集）

- 调参集：`regulatory_dev.json`，16 题（可答 8 / 超范围 5 / 要求编造条款 3），模拟问题。
- 阶段 2 实测（权重 0.4 覆盖度 + 0.3 向量余弦 + 0.3 RRF 归一化）：
  - 可答类分数 0.709 – 0.915；超范围类分数 0.429 – 0.520。
  - 初值 0.35 不能区分两类；改为 0.60（位于 0.520 与 0.709 之间）。
  - RRF 归一化分几乎恒为 0.90 – 1.00（第一名通常在两路都排第一），区分力很弱；区分主要来自关键词覆盖度。
- 局限：调参集只有 16 题，0.60 两侧余量仅约 0.09 / 0.11，不保证泛化；这是启发式门控，不是校准过的概率。
- 阶段 6 的评测集是另外的问题，不得据评测结果回头改此阈值。

## 重排调参记录（阶段 2 补充）

调参集扩至 24 题（可答 16：其中 8 题带人工指定的期望章节于阶段 2 探测后加入；拒答 8）。
度量脚本：`python scripts/dev_report.py [--no-rerank] [-v]`。
指标：hit = 引用中含期望章节的题占比；precision = 引用中属于期望章节的比例（期望章节是人工指定的窄集合，
会把其他相关章节也算作“无关”，因此 precision 是偏保守的下界，只用于前后对比）。

| 配置 | hit | precision | 平均引用数 |
|---|---|---|---|
| 无重排（句子按重叠词数打分） | 15/16 | 23/64 = 0.359 | 4.00 |
| 重排（IDF 加权 + 标题加分），无块级门槛 | 16/16 | 24/54 = 0.444 | 3.38 |
| 重排 + chunk_floor 0.75 | 16/16 | 26/51 = 0.510 | 3.19 |
| 重排 + chunk_floor 0.80（采用） | 16/16 | 27/45 = 0.600 | 2.81 |
| 重排 + chunk_floor 0.85 | 16/16 | 28/43 = 0.651 | 2.69 |
| 重排 + chunk_floor 0.90 | 15/16 | 27/34 = 0.794 | 2.12 |
| 重排 + chunk_floor 0.95 | 15/16 | 23/27 = 0.852 | 1.69 |

chunk_floor 在 0–0.7 之间完全无效（分数集中，几乎没有块低于第一名的 70%），0.8 起生效，0.9 起开始漏掉期望章节。
选 0.8：保留到“漏命中”悬崖前的一档余量。拒答类 8/8 在所有配置下不变（重排不影响 confidence 与拒答判定）。
局限：24 题的调参集上选参，不保证泛化；阶段 6 评测集是另一批问题。
